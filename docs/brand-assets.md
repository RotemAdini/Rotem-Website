# נכסי מותג — איפה כל קובץ אמור לשבת

המסמך הזה קיים כדי שברגע שהקבצים הסופיים מוכנים, אפשר יהיה פשוט להניח אותם
במקום הנכון בלי לגעת בקוד. שום קובץ אינו נוצר כאן באופן זמני: אייקון או תמונת
שיתוף "זמניים" מתפרסמים לרשתות החברתיות ונשמרים אצלן במטמון, ולכן עדיף בלי.

נכון להיום **אין באתר אף אחד מהקבצים האלה**, וזו גם הסיבה שבשיתוף קישור
לעמוד הבית או לעמוד משפטי לא מופיעה תמונה.

---

## 1. אייקון הדפדפן (favicon)

| | |
|---|---|
| קובץ | `app/icon.png` |
| גודל | 512×512 |
| פורמט | PNG עם רקע שקוף, או רקע מלא אם הלוגו בהיר |
| נדרשת עריכת קוד? | **לא** |

Next.js מזהה את הקובץ לפי שמו ומיקומו ומייצר ממנו את כל תגי ה-`<link rel="icon">`
לבד, כולל גרסאות בגדלים שונים. אין צורך להוסיף שורה כלשהי ב-`app/layout.tsx`.

אפשר גם `app/favicon.ico` במקום, אבל `icon.png` בגודל אחד גדול הוא הפשוט יותר
לתחזוקה ו-Next גוזר ממנו את השאר.

## 2. אייקון למסך הבית בנייד (Apple touch icon)

| | |
|---|---|
| קובץ | `app/apple-icon.png` |
| גודל | 180×180 |
| פורמט | PNG **ללא שקיפות** — iOS ממלא שקיפות בשחור |
| נדרשת עריכת קוד? | **לא** |

חשוב: iOS מוסיף בעצמו את הפינות המעוגלות, אז הקובץ צריך להיות ריבוע מלא.

## 3. תמונת ברירת מחדל לשיתוף (Open Graph)

| | |
|---|---|
| קובץ | `public/og-default.jpg` |
| גודל | 1200×630 |
| פורמט | JPEG או PNG, עד 1MB |
| נדרשת עריכת קוד? | **כן — שורה אחת** |

זו התמונה שתופיע כשמשתפים קישור לעמוד שאין לו תמונה משלו: דף הבית, ארבעת
עמודי הריכוז (`/recipes`, `/dates`, `/games`), `/about`, `/faq`, `/contact`
ושלושת העמודים המשפטיים.

אחרי הנחת הקובץ יש לשנות ב-[`lib/seo.ts`](../lib/seo.ts) שורה אחת:

```ts
const DEFAULT_OG_IMAGE: string | null = "/og-default.jpg";
```

כל העמודים בונים את המטא-דאטה שלהם דרך `pageMetadata()`, ולכן כולם יקבלו
אותה מיד, בלי שינוי נוסף.

**להשאיר טקסט במרכז.** חלק מהאפליקציות חותכות את הקצוות, ולכן כדאי שכל טקסט
או לוגו יישבו בשני השלישים האמצעיים.

## 4. תמונות שיתוף לעמודי המשחקים

אלה **אינן** קבצים בקוד — הן נקראות מ-Sanity, מתוך שדה `legacyImages` של כל
משחק, מהרשומה שה-`role` שלה הוא `main`.

מצב נוכחי:

| משחק | יש תמונה? |
|---|---|
| היער הקסום | ✅ `games/assets/forest/forest-moonlit-pines.jpg` |
| מירוץ האהבה | ❌ חסר |
| משחק הזיכרון הגדול | ❌ חסר |
| החבילה המלאה | ❌ חסר |

שלושת החסרים מתווספים דרך ה-Studio, בלי שינוי קוד — העמודים כבר יודעים
לקרוא אותם. מומלץ שהתמונה תהיה ביחס רוחב-גובה קרוב ל-1200×630, מאותה סיבה
שבסעיף 3.

> שימו לב: עמודי `היער הקסום` ו`מירוץ האהבה` הם היחידים באתר שעדיין אין להם
> תגי `canonical` ו-Open Graph בקוד, כי הם מטופלים בפרויקטים נפרדים. שלוש
> שורות בתוך `generateMetadata()` משלימות אותם — אפשר להעתיק מ-
> [`app/games/memory-game/page.tsx`](../app/games/memory-game/page.tsx).

## 5. מה שעדיין לא נדרש

- **`manifest.json` / PWA** — נדרש רק אם רוצים שהאתר יהיה ניתן להתקנה
  כאפליקציה. לא קיים ולא נדרש להשקה.
- **לוגו כקובץ SVG** — הכותרת והפוטר מציגים כרגע את השם כטקסט עם לב. זה עובד
  ונגיש; קובץ לוגו יידרש רק אם מחליטים להחליף אותם.
