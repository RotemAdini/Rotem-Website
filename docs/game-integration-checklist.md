# שילוב משחק חדש באתר — רשימת בדיקה

שלושת המשחקים נבנים בפרויקטים נפרדים. המסמך הזה הוא מה שעוברים עליו **כשמשחק
מוכר כמוכן** ולפני שהוא נכנס לריפו הזה. אין לבצע ממנו דבר לפני כן.

המשחקים: היער הקסום, מירוץ האהבה, משחק הזיכרון הגדול.

---

## א. לפני ההעברה — לבדוק בפרויקט המשחק

| # | בדיקה | למה |
|---|---|---|
| 1 | **מזהה יציב** — `forest-game` / `race-game` / `memory-game` | זה כבר ה-slug ב-Sanity, בכתובת ובשם התיקייה. שינוי שלו שובר קישורים קיימים |
| 2 | **מסלול** `/games/<id>/play` | עמוד המכירה נשאר ב-`/games/<id>`. המשחק עצמו יושב תחתיו, כך ששניהם חולקים מזהה אחד |
| 3 | **תאימות React/Next** | האם המשחק רץ כרכיב React, או כ-HTML מוזרק עם סקריפט וניל כמו העמודים הקיימים? השנייה עובדת — זה מה שעושים היום — אבל היא מחייבת את כל שאר הסעיפים כאן |
| 4 | **נתיבי נכסים מוחלטים מהשורש** — `/games/assets/<id>/…` | נתיב יחסי נשבר ברגע שהעמוד מוגש מכתובת עם עומק אחר |
| 5 | **CSS בתוך scope** | העמודים הקיימים עוטפים ב-`@scope (.game-content)`. **מלכודת מוכחת:** אלמנט שיושב מחוץ ל-`<main class="game-content">` לא מקבל אף כלל — כך נשבר סרגל הרכישה הנייד בארבעת העמודים היום |
| 6 | **מרחב שמות ב-localStorage** — `rotem-game-<id>:*` | האתר כבר משתמש ב-`rotemFavorites`, `rotemIngredientChecks:*` ו-`rotem-accessibility-preferences`. התנגשות תמחק העדפות של מבקר |
| 7 | **אין לוגיקת תשלום או הרשאות בתוך המשחק** | ההרשאה נקבעת בשרת. משחק שבודק בעצמו אם ״שולם״ הוא משחק שאפשר לפתוח מה-DevTools |
| 8 | **אין מפתחות** | לא מפתח Supabase, לא מפתח Resend, לא סוד Grow. הקוד של המשחק מוגש לדפדפן במלואו |
| 9 | **`game_id` במשוב** | המשוב בסוף המשחק כותב לפרויקט Supabase נפרד. ה-`game_id` חייב להיות אותו מזהה מסעיף 1, אחרת אי אפשר לפלח את התוצאות |
| 10 | **כפתור נגישות** | המשחק **לא** מממש פאנל משלו. הוא שולח:<br>`window.dispatchEvent(new CustomEvent("rotem:accessibility-open"))`<br>הפאנל הקיים נפתח והמיקוד עובר אליו. הקבוע ב-`lib/accessibility-preferences.ts` |
| 11 | **פריסת מסך מלא ונייד** | טריגר הנגישות: 44×44, `position: fixed`, `inset-block-end: max(12px, env(safe-area-inset-bottom))`, שקיפות 35% במנוחה ומלאה ב-hover/focus. **לעולם לא מוסתר לגמרי** (WCAG 2.2 SC 2.4.11) |
| 12 | **הבנייה עוברת** | `npx tsc --noEmit`, `npm run lint`, `npm run build` — ירוקים אחרי ההעברה |

## ב. אחרי ההעברה — בריפו הזה

- [ ] `generateMetadata()` בעמוד המכירה: להוסיף `path` ו-`image` דרך `pageMetadata()`.
      **היער הקסום ומירוץ האהבה הם שני העמודים היחידים באתר שעדיין חסרים
      canonical ו-Open Graph.** שלוש שורות — להעתיק מ-`app/games/memory-game/page.tsx`
- [ ] תמונת מוצר ב-Sanity: `legacyImages` עם `role: "main"`. קיימת רק ליער הקסום;
      חסרה למירוץ האהבה, למשחק הזיכרון ולחבילה
- [ ] `/games/<id>/play` ל-`app/sitemap.ts` — רק אם העמוד אמור להיות אינדקסבילי.
      אם הוא מאחורי רכישה, עדיף `noIndex` ולא להוסיף אותו
- [ ] לתקן את באג ה-`@scope` של `.sticky-buy` (סעיף א׳5) בזמן שנוגעים בעמודים ממילא
- [ ] להעלות את טריגר הנגישות מעל סרגל הרכישה הנייד ברגע שהסרגל יתוקן — הוא
      יושב על `left:10px; bottom:10px` ונופל בדיוק על כפתור הקריאה לפעולה ב-RTL
- [ ] לעדכן את מדיניות הפרטיות: **המשוב בסוף המשחק אינו מתועד בה כלל היום**.
      נדרשת תוספת לסעיפים 5, 10 ו-13 — איזה פרויקט Supabase, מה נשמר, כמה זמן
- [ ] הצהרת הנגישות סעיף 6: לעדכן את המגבלה על טפסי המשחקים אם היא כבר לא נכונה

## ג. מה מוסר כשכל שלושת המשחקים משולבים

**אין לבצע דבר מזה כעת.** משחק הזיכרון הישן עדיין משתמש ב-SendMsg והוא הטופס
היחיד שאוסף נרשמים אמיתיים.

### אפשר להסיר כבר עכשיו — אף אחד לא תלוי בהם

- `data-track-checkout` ו-`data-track-value` בארבעת הטפסים — סמני אנליטיקה
  מתים, שום קוד לא קורא אותם. **אין להחליף אותם באנליטיקה אמיתית**
- הכפילויות הישנות שאינן מוגשות: `games/{memory-game,bundle,forest-game,race-game}.html`,
  `games/js/main.js`
