# רותם עדיני — אתר V2

גרסת אב-טיפוס מרובת עמודים שממשיכה את דף הבית המקורי ומרחיבה אותו לשאר האתר.

## מה יש בפרויקט

- `index.html` — דף הבית המעודכן
- `recipes.html` — אינדקס מתכונים עם חיפוש וסינון
- `recipe.html` — עמוד מתכון בודד
- `dates.html` — רעיונות לדייטים עם סינון
- `games.html` — קטלוג המשחקים האמיתי, עם קישורים לעמודי `games/forest-game.html`, `games/race-game.html`, `games/memory-game.html` ו-`games/bundle.html`
- `gifts.html` — מתנות מומלצות עם פילטרים (הקטלוג עצמו עדיין ריק — אין רעיונות מתנה אמיתיים מחוברים)
- `about.html` — קצת עליי
- `contact.html` — צור קשר
- `account.html` — התחברות והרשמה
- `styles.css` — עיצוב משותף לכל האתר
- `script.js` — אינטראקציות, פילטרים ומועדפים

## שינויים בדף הבית

- אזור "ברוכים הבאים" נמצא בצד ימין.
- התמונה נמצאת משמאל.
- במקום גבול חד בין הטקסט לתמונה יש מעבר רך באמצעות gradient + CSS mask.
- נשמר סקרול הקטגוריות העגולות.
- נשמרו אזורי "המתכונים האחרונים" ו"רעיונות לדייטים".
- החלק התחתון הועדן: במקום שלושה אזורים צפופים עם הרבה מוצרים יש שלושה previews גדולים וקלים יותר.

## מה עובד כבר ב-JavaScript

- חיפוש ופילטרים בעמוד המתכונים
- מיון מתכונים
- פילטרים בעמוד הדייטים
- פילטרים במשחקים ובמתנות
- מועדפים נשמרים ב-`localStorage`
- סימון מצרכים בעמוד מתכון
- העתקת קישור למתכון
- Tabs של התחברות / הרשמה
- תפריט מובייל
- Toasts
- טפסי demo

## מה עדיין דמו

- Backend
- משתמשים אמיתיים
- מסד נתונים
- סליקה ורכישות
- שליחת טופס צור קשר
- ניוזלטר אמיתי
- התמונות והטקסטים האמיתיים שלך
- CMS / פאנל ניהול

## איך לפתוח

1. חלצי את ה-ZIP.
2. פתחי `index.html` בדפדפן.
3. עברי בין הדפים דרך התפריט.
4. התמונות כרגע נטענות מ-Unsplash, ולכן צריך חיבור לאינטרנט.

## שלב מומלץ הבא

אחרי שנאשר את מבנה המסכים, אפשר להעביר את הפרויקט ל-Codex יחד עם תיקיית המתכונים האמיתית ולבקש ממנו:
1. ליצור `recipes.json`.
2. להחליף את תוכן הדמו בתוכן האמיתי.
3. לחבר routing/framework אם נחליט לעבור ל-React/Next.js.
4. בהמשך לחבר Auth, DB וסליקה.

## V4 — ניקוי תוכן דמו וחיבור משחקים אמיתיים

- הוסרו `game.html`, `play.html` ו-`checkout.html` — הם ייצגו מוצר משחק בדוי ("דיבורים מהלב") שלא היה חלק מהקטלוג האמיתי. שלושתם הוחלפו בעמודי הפניה ל-`games.html`.
- `recipe.html` ו-`date.html` הם כעת תבניות משותפות בלבד: בלי `?series=...&item=...` תקין הן מציגות מצב ריק כן ("המתכון/הרעיון לא נמצא") במקום תוכן דמו בדוי.
- הוסר תוכן בדוי נוסף: הסטטיסטיקות בעמוד ההתחברות, היסטוריית הרכישות והמשחק שנרכש בדשבורד, וכרטיסי המתכונים/דייטים/מתנות הכפולים שהיו שוכבים בקוד המקור אך תמיד הוחלפו ב-JS.
- קישורי הרשתות החברתיות בפוטר עודכנו לחשבונות האמיתיים של רותם (הועתקו מעמודי המשחקים), במקום `href="#"`.
- לעמודי המשחקים (`games/*.html`) הוסרה כותרת/תחתית כפולה שהייתה קיימת בקוד אך מוסתרת ב-CSS בלבד.
- לכל קובצי ה-CSS/JS נוסף פרמטר גרסה (`?v=...`) כדי שדפדפנים — בעיקר Safari באייפון — יטענו תמיד את הגרסה העדכנית אחרי דיפלוי. יש לעדכן את הפרמטר הזה בכל דף שנוגעים בו יחד עם שינוי ב-CSS/JS.
