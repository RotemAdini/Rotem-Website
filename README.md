# רותם עדיני — אתר V2

גרסת אב-טיפוס מרובת עמודים שממשיכה את דף הבית המקורי ומרחיבה אותו לשאר האתר.

## מה יש בפרויקט

- `index.html` — דף הבית המעודכן
- `recipes.html` — אינדקס מתכונים עם חיפוש וסינון
- `recipe.html` — עמוד מתכון בודד
- `dates.html` — רעיונות לדייטים עם סינון
- `games.html` — עמוד חנות/קטלוג משחקים
- `game.html` — עמוד מוצר למשחק
- `gifts.html` — מתנות מומלצות עם פילטרים
- `about.html` — קצת עליי
- `contact.html` — צור קשר
- `account.html` — התחברות והרשמה
- `styles.css` — עיצוב משותף לכל האתר
- `script.js` — אינטראקציות, פילטרים ומועדפים

## שינויים בדף הבית

- אזור "ברוכים הבאים" נמצא בצד ימין.
- התמונה נמצאת משמאל.
- במקום גבול חד בין הטקסט לתמונה יש מעבר רך באמצעות gradient + CSS mask.
- נשמר סקרול הקטגוריות העגולות.
- נשמרו אזורי "המתכונים האחרונים" ו"רעיונות לדייטים".
- החלק התחתון הועדן: במקום שלושה אזורים צפופים עם הרבה מוצרים יש שלושה previews גדולים וקלים יותר.

## מה עובד כבר ב-JavaScript

- חיפוש ופילטרים בעמוד המתכונים
- מיון מתכונים
- פילטרים בעמוד הדייטים
- פילטרים במשחקים ובמתנות
- מועדפים נשמרים ב-`localStorage`
- סימון מצרכים בעמוד מתכון
- העתקת קישור למתכון
- Tabs של התחברות / הרשמה
- תפריט מובייל
- Toasts
- טפסי demo

## מה עדיין דמו

- Backend
- משתמשים אמיתיים
- מסד נתונים
- סליקה ורכישות
- שליחת טופס צור קשר
- ניוזלטר אמיתי
- התמונות והטקסטים האמיתיים שלך
- CMS / פאנל ניהול

## איך לפתוח

1. חלצי את ה-ZIP.
2. פתחי `index.html` בדפדפן.
3. עברי בין הדפים דרך התפריט.
4. התמונות כרגע נטענות מ-Unsplash, ולכן צריך חיבור לאינטרנט.

## שלב מומלץ הבא

אחרי שנאשר את מבנה המסכים, אפשר להעביר את הפרויקט ל-Codex יחד עם תיקיית המתכונים האמיתית ולבקש ממנו:
1. ליצור `recipes.json`.
2. להחליף את תוכן הדמו בתוכן האמיתי.
3. לחבר routing/framework אם נחליט לעבור ל-React/Next.js.
4. בהמשך לחבר Auth, DB וסליקה.


## V3 — תוספות חדשות

נוספו גם:
- `favorites.html` — מועדפים עם טאבים לפי סוג תוכן
- `date.html` — עמוד דייט בודד
- `dashboard.html` — אזור אישי אחרי התחברות
- `play.html` — חוויית משחק דיגיטלית עובדת כדמו
- `checkout.html` — מסך Checkout
- `search.html` — חיפוש גלובלי בכל סוגי התוכן
- `404.html` — עמוד שגיאה מעוצב

נוספו חיבורים בין העולמות:
- מתכון → דייט + משחק
- דייט → מתכון + משחק
- דף הבית → קומבינציות לערב שלם

המועדפים משתמשים ב-`localStorage`, והמשחק הדיגיטלי כולל כרגע 8 קלפים/שאלות לדוגמה.
