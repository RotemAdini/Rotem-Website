# רותם עדיני — אתר

אתר Next.js (App Router) עם מתכונים, רעיונות לדייטים ומשחקים זוגיים דיגיטליים.
התוכן מנוהל ב-Sanity, ההתחברות והמועדפים ב-Supabase.

> **מצב:** לפני השקה. האתר עדיין אינו מקוון. ראו [`docs/launch-readiness.md`](docs/launch-readiness.md).

---

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # ומלאו את הערכים
npm run dev                  # http://localhost:3000
```

`.env.example` מתעד כל משתנה סביבה, מה הוא עושה ואילו מהם סודיים. שום ערך אמיתי
אינו נמצא ב-Git: `.env.local` מוחרג.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בניית ייצור (מושכת תוכן מ-Sanity ומייצרת את ההפניות) |
| `npm run start` | הרצת ה-build שנבנה |
| `npm run lint` | ESLint |
| `npm run test:auth` | בדיקות: רענון סשן, מועדפים, טופס יצירת קשר |
| `npm run migration:*` | כלי מיגרציית התוכן החד-פעמית (ראו `scripts/`) |

## מבנה

| תיקייה | תוכן |
|---|---|
| `app/` | עמודים ומסלולים (App Router), `sitemap.ts`, `robots.ts` |
| `components/` | רכיבי UI משותפים |
| `lib/` | שכבת הנתונים (`lib/sanity/`), התחברות (`lib/supabase/`), מועדפים, SEO, טופס יצירת קשר |
| `content/games/` | ה-HTML הפנימי של ארבעת עמודי המשחקים, מוזרק כמו שהוא |
| `public/` | כל מה שמוגש לדפדפן — תמונות, סקריפטים ונכסי המשחקים |
| `sanity/` | סכמות התוכן וה-Studio (מוטמע ב-`/studio`) |
| `supabase/migrations/` | סכמת מסד הנתונים |
| `docs/` | תיעוד עבודה: מוכנות להשקה, נכסי מותג, ארכיטקטורת מסחר |
| `scripts/`, `data/`, `reports/`, `tests/`, `tools/` | כלי מיגרציה, חומרי מקור, דוחות ובדיקות |

### תיקיות שאינן חלק מהאתר המוגש

`images/`, `recipes/` ו-`games/` בשורש הם ארכיון: העתקי מקור של תמונות ושרידים
מאתר הפרוטוטיפ הסטטי שקדם ל-Next. **הם אינם מוגשים** — האתר מגיש רק את
`public/`. הם נשארים בריפו בכוונה, כגיבוי ולצורך השוואה, ומוסיפים כ-590MB לכל
שכפול של הריפו. ראו את דוח המוכנות להמלצה בנושא.

## החלטות ארכיטקטורה שכדאי להכיר לפני שנוגעים בקוד

- **`listed` הוא שער הפרסום.** פריט עם `listed:false` — מתכון או רעיון לדייט —
  אינו נגיש בשום מקום: לא ברשימות, לא בחיפוש, לא ב-sitemap, לא בכתובת שלו
  (404), ולא דרך כתובות legacy. השער משורשר דרך כל פונקציית קריאה ב-
  `lib/sanity/recipes.ts` ו-`lib/sanity/dates.ts`, ואין פונקציה שקוראת בלעדיו.
  **זה אינו סמן כפילויות.**
- **הפניות legacy נוצרות בזמן build** מ-Sanity, ב-`next.config.ts` (176 מתכונים,
  13 דייטים). אין להוסיף עותק ידני שלהן בקובץ אחר — הוא יתיישן.
- **`dynamicParams = false`** בשני המסלולים הדינמיים, כדי ש-slug לא מוכר יחזיר
  404 אמיתי ולא 200 עם גוף של עמוד שגיאה. המחיר: תוכן חדש ב-Sanity דורש deploy.
- **מטא-דאטה** נבנית תמיד דרך `pageMetadata()` ב-`lib/seo.ts` — כותרת, תיאור,
  canonical, Open Graph וכרטיס Twitter ממקור אחד.
- **סודות** נקראים רק ממודולים המסומנים `server-only`. שום מפתח אינו נושא קידומת
  `NEXT_PUBLIC_`.
- **עמודי המשחקים** מזריקים HTML כמו שהוא מ-`content/games/`. ה-CSS שלהם עטוף
  ב-`@scope (.game-content)`, ולכן אלמנט שיושב מחוץ ל-`<main class="game-content">`
  לא יקבל אף כלל עיצוב.

## נגישות

הנגישות נמצאת בקוד עצמו — סמנטיקה, ניגודיות, תמיכה במקלדת ושמות פקדים. כפתור
הנגישות שבפינה הוא תוספת נוחות בלבד (ניגודיות גבוהה, הדגשת קישורים) ואינו הופך
את האתר לנגיש. **אין להתקין תוסף נגישות חיצוני מכל סוג.** ההצהרה המלאה ב-
`/accessibility`, והיא נמנעת במכוון מהכרזה על עמידה בת"י 5568.

## פריסה

היעד הוא **Netlify**. `netlify.toml` מכיל את פקודת הבנייה ואת נעילת גרסת Node.
הוא אינו מגדיר הפניות או כותרות — אלה נוצרות ב-`next.config.ts`. השרידים של
Vercel (`.vercel/`, `.vercelignore`) הם מהעלאות תצוגה מקדימה ואינם בשימוש.
